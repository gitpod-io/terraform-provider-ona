# ona_skill (Data Source)

Reads one organization-level Ona skill by its Prompt UUID. Organization scope is resolved from the configured provider token.

The configured token selects the organization and must have Prompt read permission and access to the Ona Agents feature tier. The returned attributes can be referenced by other Terraform configuration, including the complete Markdown prompt content.

## Example Usage

```terraform
data "ona_skill" "security_review" {
  skill_id = "00000000-0000-0000-0000-000000000000"
}

output "security_review_name" {
  value = data.ona_skill.security_review.name
}

output "security_review_prompt" {
  value = data.ona_skill.security_review.prompt
}
```
