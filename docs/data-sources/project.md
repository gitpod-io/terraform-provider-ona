# ona_project (Data Source)

Fetches an Ona project by ID and exposes the same fields as the `ona_project` managed resource.

For product context, see [Project configuration](https://ona.com/docs/ona/projects/overview) and [Create your first project](https://ona.com/docs/ona/create-first-project).

## Example Usage

```terraform
data "ona_project" "example" {
  project_id = "<project-id>"
}
```

## Schema

### Required

- `project_id` (String) Ona project ID to look up.

### Read-Only

- `automations_file_path` (String) Path to the tasks and services configuration, relative to the repository root.
- `branch` (String) Git branch name Ona uses when creating environments and prebuilds.
- `created_at` (String) Time when the project was created.
- `creator` (Attributes) Identity that created the project. (see [below for nested schema](#nestedatt--creator))
- `devcontainer_file_path` (String) Path to the devcontainer file, relative to the repository root.
- `environment_class` (Attributes List) Environment classes available to this project, in priority order. (see [below for nested schema](#nestedatt--environment_class))
- `id` (String) Terraform data source ID. This is the same value as `project_id`.
- `insights_enabled` (Boolean) Whether Ona Insights is enabled for the project.
- `name` (String) Project display name shown in Ona.
- `prebuild_configuration` (Attributes List) Prebuild configuration for the project. (see [below for nested schema](#nestedatt--prebuild_configuration))
- `repository_clone_url` (String) Git repository clone URL.
