# ona_integration (List Resource)

Lists all Ona organization integrations, including runner-scoped and externally installed integrations. Credential values are omitted.

For product context, see [Integrations](https://ona.com/docs/ona/integrations/overview) and [MCP servers](https://ona.com/docs/ona/mcp). List resources are used by Terraform Query and require Terraform CLI `>= 1.14`.

## Example Usage

```terraform
list "ona_integration" "all" {
  provider         = ona
  include_resource = true
}
```
