# ona_skill (List Resource)

Lists importable organization-level Ona skills. Template/skill hybrids are excluded because `ona_skill` cannot manage them.

The configured token selects the organization and must have Prompt read permission and access to the Ona Agents feature tier.

## Example Usage

```terraform
list "ona_skill" "security" {
  provider         = ona
  include_resource = true

  config {
    search = "security"
  }
}
```

## Generate import configuration

Run the query with Terraform 1.14 or later and write generated resource and import blocks to a new file:

```shell
terraform query -generate-config-out=generated-skills.tf
```

Review the generated configuration, run `terraform apply` to import the skills, and then run `terraform plan`. The final plan should be empty when the checked-in prompt content matches Ona.
