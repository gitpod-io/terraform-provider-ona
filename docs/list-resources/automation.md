# ona_automation (List Resource)

Lists importable persistent Ona automations. System-managed, deleting, report-based, and unsupported legacy automations are excluded.

For product context, see [Background automations](https://ona.com/docs/ona/automations/overview) and [Configure Automations](https://ona.com/docs/ona/automations/configure-automations). List resources are used by Terraform Query and require Terraform CLI `>= 1.14`.

## Example Usage

```terraform
list "ona_automation" "all" {
  provider         = ona
  include_resource = true
}
```
