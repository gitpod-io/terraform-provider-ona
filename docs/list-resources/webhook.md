# ona_webhook (List Resource)

Lists Ona webhooks that can be imported and managed by Terraform. Webhook signing secrets are never read or returned.

For product context, see [Webhooks](https://ona.com/docs/ona/automations/webhooks) and [Automation triggers](https://ona.com/docs/ona/automations/configure-automations). List resources are used by Terraform Query and require Terraform CLI `>= 1.14`.

## Example Usage

```terraform
list "ona_webhook" "all" {
  provider         = ona
  include_resource = true
}
```
