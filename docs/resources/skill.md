# ona_skill (Resource)

Manages an organization-level Ona skill. Organization scope is resolved from the configured provider token. The token must have Prompt management permission and access to Ona Agents.

The configured token selects the organization and must have Prompt management permission and access to the Ona Agents feature tier.

## Lifecycle behavior

Changes to `name`, `description`, prompt content, and command additions or renames update the existing skill. Removing `command` replaces the skill because the Ona API cannot safely clear a stored command value.

Removing the resource from configuration or running `terraform destroy` deletes the skill from Ona. Terraform accepts an already-missing skill only when the configured token is still scoped to the organization recorded in private state; changing organizations produces an error instead of deleting or recreating the skill across organizations.

## Example Usage

```terraform
resource "ona_skill" "security_review" {
  name        = "Security review"
  description = "Review changes against the organization's security checklist."
  prompt      = file("${path.module}/security-review.md")
  command     = "security-review"
}
```

## Schema

### Required

- `description` (String) Description of when and why agents should use the skill.
- `name` (String) Human-readable skill name.
- `prompt` (String) Skill instructions. Use Terraform's `file()` or `templatefile()` to keep this Markdown content in the repository.

### Optional

- `command` (String) Optional slash-command name. It must be unique in the organization and contain only ASCII letters, digits, underscores, and hyphens. Adding or renaming a command updates in place; removing it replaces the skill because Ona cannot clear a stored command value.

### Read-Only

- `id` (String) Stable UUID of the skill Prompt returned by Ona.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) accepts the Prompt UUID, for example:

```shell
#!/usr/bin/env sh

terraform import ona_skill.security_review 00000000-0000-0000-0000-000000000000
```
