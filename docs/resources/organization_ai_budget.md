# ona_organization_ai_budget (Resource)

Mode-specific monthly Ona AI budget default for the organization associated with the configured provider token. This feature requires an enterprise organization and suitable Billing permissions.

The provider resolves the organization from its authenticated token. Use separate `credits` and `byok` resources to manage both organization defaults. A zero policy limit is an explicit cap, not an omitted limit.

## Example Usage

```terraform
resource "ona_organization_ai_budget" "credits" {
  mode                 = "credits"
  monthly_credit_limit = 5000
}

resource "ona_organization_ai_budget" "byok" {
  mode                          = "byok"
  monthly_cost_limit_microunits = 100000000
  currency                      = "usd"
}
```

## Schema

### Required

- `mode` (String) Budget mode: `credits` or `byok`. Changing this value replaces the resource.

### Optional

- `currency` (String) Currency for a BYOK cost limit: `usd`, `eur`, or `gbp`.
- `monthly_cost_limit_microunits` (Number) Monthly BYOK cost limit in currency microunits for `byok` mode. Must be non-negative.
- `monthly_credit_limit` (Number) Whole-credit monthly limit for `credits` mode. Configure a value from 0 through 9,223,372,036,854.

### Read-Only

- `created_at` (String) Policy creation time in RFC 3339 format.
- `id` (String) Billing policy ID.
- `organization_id` (String) Organization ID resolved from the configured provider token.

## Import

Import is supported with `organization_id/mode`. The organization must match the configured provider token.

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:
